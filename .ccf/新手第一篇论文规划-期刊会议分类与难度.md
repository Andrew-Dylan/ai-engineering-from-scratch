# 新手第一篇论文规划：期刊 / 会议分类 · 难度分级 · 18 个月路线图

> 面向方向：自动驾驶 · VRU（弱势道路使用者）· 智能骑行
> 基准日期：**2026-09-20**｜依据：CCF 第七版目录（2026-03-31 发布）
> 难度星级为**经验性判断**，依据 = 录取率 / 审稿门槛 / 对实验量的要求 / 新手独立完成的成功率。
> 带 ✅ 的日期为**已核实**的官网日期；标「约」的为往年规律，投稿前务必再查官网。

---

## 第 0 步：先接受三个反直觉的事实

1. **CCF 等级 ≠ 投稿难度。**
   - TITS 只是 B，但竞争与审稿强度高于不少 A 刊；
   - IROS 只是 C，但录取率约 39–45%，是机器人方向最好中的正会之一；
   - VRIH 是 C 且相对友好，适合第一次走流程。
2. **会议和期刊对新手是两种完全不同的游戏。**
   - **会议**：有 deadline → 逼你出结果；反馈快（2–4 个月）；中/不中泾渭分明。**新手第一篇应优先会议。**
   - **期刊**：无 deadline 但周期长（一审 2–6 个月，全流程 8–18 个月），可反复修改。**适合作为第二篇，或会议的扩展版。**
3. **第一篇的目标不是「发得高」，而是「走完全流程 + 拿到第一个 accepted」。**
   有了一篇 C/中等 venue，第二篇冲 B/A 的信心、写作模板、审稿经验都会完全不同。

## 3.3 新手友好的选题模板（按成功率排序）

**模板 A · 评测/失效分析型（最稳，强烈推荐）**
> 「现有 VRU 检测 / 轨迹预测模型在 *X 条件*（夜间、雨天、遮挡、非机动车道、密集混行）下的系统性评测与改进」

- 优点：不需要发明全新架构；实验驱动；数据集现成；结论天然有贡献。
- 目标：IEEE IV / ITSC / IROS，或 IVC / MVA / TIST。
- 关键：评测维度要新（不能只是刷榜），并给出**可操作的改进**。

**模板 B · 跨域迁移型**
> 「把 *某成熟方法*（如行人轨迹预测、BEV 感知、占据栅格）迁移到 **电动自行车/骑行场景**，并指出域差与适配方案」

- 优点：方法有出处，风险低；骑行场景本身稀缺 → 天然 novelty。
- 目标：IROS / ITSC / IEEE IV；期刊 JATS、PMC。
- 数据集：INTERACTION、inD/rounD/exiD（含骑行者）、自采手机 IMU/GPS。

**模板 C · 传感+识别型（HCI/普适计算路线）**
> 「基于手机/手表 IMU 的骑行者危险行为识别与近失事件（near-miss）检测」

- 优点：数据可自采（成本低），方法可用经典 ML/DL；对算力要求低。
- 目标：PERCOM / MobileHCI / PMC / PUC / CCF TPCI。
- 注意：自采数据需伦理审查（IRB），**提前 4–6 周启动**。

**模板 D · 系统+小规模用户研究（XR 路线）**
> 「骑行 AR 抬头显示 / 导航提示的原型与 10–12 人用户研究」

- 优点：ISMAR/VRST 类会议重视原型与可用性，不苛求 SOTA。
- 目标：ISMAR / VRST / ICXR / IEEE VR（后者难度高）。
- 注意：任何涉及人的实验**必须有 IRB 审批**，且需报告被试人口学信息。

**模板 E · 综述（不建议作为第一篇）**
> 综述耗时长、期刊综述多为邀稿，且难以体现个人贡献。留到博士阶段。

# 第四部分：避坑清单（新手最常踩的 12 个坑）

1. **选题太大**：「自动驾驶安全」写不了；要收窄到「雨天夜间非机动车道上的骑行者检测」。
2. **没有 baseline**：只有自己的方法 = 必然被拒。**先跑通 2–3 个基线再想创新。**
3. **数据集不公开**：无法复现 = 无法通过评审。公开数据集优先，自采必开源。
4. **实验量不足**：顶会需要主实验 + 消融 + 可视化 + 失败分析；只有一张表必拒。
5. **一稿多投**：会议评审期内投其他会议/期刊 = 直接 desk reject，学术污点。
6. **会议扩展期刊**：通常需要 **≥30% 新内容**，且必须引用原会议论文。
7. **双盲被破**：CVPR/ECCV/IEEE VR 等强制双盲，匿名化失败 = desk reject。
8. **IRB 缺失**：任何人类被试研究（用户研究、众包标注）必须有伦理审批；IEEE VR 明确写「错误申报将 desk reject」。
9. **arXiv 预印本**：多数会议允许，但可能破坏双盲；不确定就别挂。
10. **卡点提交**：投稿系统在截止前 2 小时必崩。**提前 3 天提交。**
11. **作者顺序/通讯作者**：投稿前和导师书面确认，避免事后纠纷。
12. **英文写作**：中式长句 + 图表模糊 = 直接被低估。用 LaTeX 模板 + 找母语者/专业润色。

## B.1 这张表推翻了哪些直觉（重要）

1. **AAAI 17.6%、IJCAI 13.6% —— 比 CVPR(25.3%) 难得多。**
   不要因为"AAAI/IJCAI 是 AI 的 B 类"就当成保底；它们投稿量爆炸，实际是全表最难档。
2. **MobiCom 12.9%、RTSS 13.7% 是全表最低。**
   车联网（V2X）方向和车载实时系统方向，别把这两个当"常规选择"。
3. **"B 类比 C 类难"不成立。**
   反例满地：PERCOM(B) 15.6% < IROS(C) 36.5%；SenSys(B) 18.7% < ICMI(C) 36.5%；ICASSP(B) 45.3% > ICCV(A) 24.0%。
   **同一领域的 C 类会议，往往才是新手真正的机会窗口。**
4. **【对你的直接结论】IROS(36.5%)、ICRA(38.0%)、3DV(40.2%)、ICASSP(45.3%) 是你在本方向最该认真准备的正会。**
   而 ITSC / IEEE IV 未公布录取率，但历史上是 ITS 社区门槛最低的正会，且与你的 VRU/骑行主题最对口。
5. **IEEE VR 是 A 类但录取率 29.4%**：数字不算低，它属**质量门槛**型（要求强贡献 + 严格双盲 + IRB）。别只看比例。

## B.2 备注与数据质量（引用时请注意）

- **来源分工**：CS Conf Stats 覆盖 CVPR、ICCV、ECCV、NeurIPS、ICML、ICLR、AAAI、IJCAI、ICRA、IROS、ACM MM、ICME、CHI、UIST、UbiComp、INFOCOM、MobiCom、SenSys、MobiSys、SIGSPATIAL、KDD、WWW、RTSS、DAC、EMSOFT、RTAS、IEEE VR；其余会议用外部来源。
- **"最近年份"≠"最近有录取率的年份"**：ACM MM 2026、SIGSPATIAL 2026、DAC 2026、MobiCom 2026 只公布了录取数、无投稿总数，故取最近可用的 2025。
- **UbiComp / IMWUT**：2016 是 CS Conf Stats 最后一个可用数据；近年 UbiComp 正会论文走 **IMWUT 期刊**，属期刊口径，已排除。
- **多轮投稿**：MobiCom（夏/冬两轮）、KDD、WWW、SenSys 一年多轮，表中为全年/研究 track 汇总。
- **推导值（非官方印刷值）**：ISMAR 2025 = 60 篇 TVCG + 157 篇会议论文 / 763；DIS 2025 官方只写 "726 submissions, 24% accepted"，~174 为推导；3DV 与 CoRL 来自第三方 OpenReview 聚合站 PaperCopilot，**CoRL 2025 数据不完整**。
- **次级来源**：ICASSP 2025 来自厂商技术博客（计数明确）；ICPR / ICIP / IPSN 来自社区 OpenReview wiki（**IPSN 自 2025 起并入 SenSys**）。
- **IEEE BigData**：18% 是 2026 CFP 中的 "regular paper 录取率"，未公布具体计数（2024 年为 18.4%）。
- **CHI 口径差异**：tdjneate 的 CHI 2025 为 1,249/5,014 = 24.9%；CS Conf Stats 按"送审稿"算 26.8%（剔除 desk reject）。本表用 CS Conf Stats 的 CHI 2026 数字。
- **ITSC / IEEE IV 无录取率**：IEEE IV 2025 官方报告仅称"选出 370 余篇研究论文"，无投稿总数。
- ⚠️ **录取率不能当个人中稿概率**：分母包含大量成熟课题组的稳定产出；新手第一次投稿的真实概率要打折。它的价值在**排序**，不在绝对值。
